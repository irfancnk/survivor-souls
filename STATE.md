## DECISIONS
- Orientation: portrait only, iOS + Android. User decision 2026-10-12.
- Render pipeline: URP. Reason: mobile perf, good look.
- Git LFS: NOT on. git-lfs not installed. Add later before big binary assets.
- Repo: public, github.com/irfancnk/survivor-souls.

- Menu UI: UI Toolkit, not uGUI. Reason: one UXML/USS per screen, easy for AI to edit, cheap on mobile.
- Scenes built by editor script. Reason: reproducible, diffable.
- Placeholder art = procedural (no Meshy access yet). One palette material for characters/props. Reason: few draw calls, swap later.
- Game lighting: realtime unshadowed point lights + trilight ambient, no bake. Reason: simple, fast on mid phones. Bake later if needed.
- Gameplay camera: Archero style, fixed yaw 0, pitch 55.
- Font: Unity default for now. No font download.

## KNOWN ISSUES
- Mac build needs `-buildTarget OSXUniversal` on Unity command line. Else URP SSAO/post shaders stripped, PC pipeline fails.
- Unity build rewrites Assets/Settings/*RPAsset + GraphicsSettings (prefilter fields). Do not commit that noise.
- `Mathf.SmoothStep` is an interpolator, not GLSL smoothstep. Use `TextureFactory.SmoothStep`.
- Batch Unity in a worktree killed a lingering IL post-process runner of the open editor once. Harmless, editor respawns it.
- Archer is placeholder quality (primitive look). Replace with Meshy model.
