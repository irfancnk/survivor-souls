## DECISIONS
- Design language: Archero / Archero 2 (menus, loop, chests, daily/weekly quests, gear merge, talents, energy). Look: Dark Souls, realistic, not dismal. User decision 2026-10-11.
- Naming map: energy=Estus, gold=Souls, gems=Ember Shards, chests=Reliquaries, daily=Oaths, weekly=Pilgrimage, chapter=Realm, room=Chamber. See GAME_PLAN sec 2.
- Art source: Meshy.ai -> FBX -> Unity URP. Paid Meshy plan for ship assets (free = CC BY, needs credit). Tri budget: hero 5-8k, enemy 1.5-3k, boss 8-12k, prop <1.5k.
- Orientation: portrait only, iOS + Android. User decision 2026-10-12.
- Render pipeline: URP. Reason: mobile perf, good look.
- Git LFS: NOT on. git-lfs not installed. Add later before big binary assets.
- Repo: public, github.com/irfancnk/survivor-souls.

- Menu UI: UI Toolkit, not uGUI. Reason: one UXML/USS per screen, easy for AI to edit, cheap on mobile.
- Scenes built by editor script. Reason: reproducible, diffable.
- Font: Unity default for now. No font download.

- Tracking: Jira site survivorsouls.atlassian.net, project SurvivorSouls (key KAN). One ticket per user task. In-dev status name = "In Development".

- Docs: Confluence space SS = source of truth for design docs. Repo Docs/ keeps copy. New doc goes to right numbered folder; old doc to 99 Archive (no delete).

## KNOWN ISSUES
- Editor batchmode `Camera.Render` preview (`-ss-preview`) leaks the last bound texture into materials with no base map. Player builds render fine. Trust a dev player screenshot over the preview for color.
- `Handheld` API exists only on iOS/Android targets: guard with `#if UNITY_IOS || UNITY_ANDROID`.
- Command-line Unity cannot run while the Editor has the project open (Temp/UnityLockfile).
- Mac build needs `-buildTarget OSXUniversal` on Unity command line. Else URP SSAO/post shaders stripped, PC pipeline fails.
- Unity build rewrites Assets/Settings/*RPAsset + GraphicsSettings (prefilter fields). Do not commit that noise.

- Agent cannot screenshot Mac screen: `screencapture` has no Screen Recording permission. Use dev build + `-ss-screenshot` instead.
